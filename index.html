Horizon

Minecraft: Java Edition 26.3, переписанный с нуля на Rust. Открытый проект под лицензией MIT: по замерам авторов мир грузится быстрее, а памяти нужно меньше, сама игра идёт без Java. Лаунчер ставит Horizon одной кнопкой: скачает файлы Minecraft 26.3, Java 25 для разовой подготовки и официальный лаунчер Horizon с GitHub.

Моды Fabric и Forge в Horizon не работают. Нужна видеокарта с поддержкой Vulkan.

    Частые вопросы

    Это бесплатно?

    Да, лаунчер бесплатный. Для входа через Microsoft нужна лицензия Minecraft Java Edition. Офлайн-аккаунты работают без входа: для локальной игры и серверов в офлайн-режиме. Аккаунт ZakhaRahkaZ тоже бесплатный и без лицензии.

    Почему Windows предупреждает при запуске?

    Установщик не подписан платным сертификатом, поэтому SmartScreen осторожничает. Сверьте SHA-256 файла с суммой на этой странице и нажмите «Подробнее → Выполнить в любом случае».

    Откуда скачивается установщик?

    С Google Диска автора. Если браузер покажет страницу Диска с предупреждением о проверке на вирусы, нажмите «Всё равно скачать»: Диск не проверяет файлы больше 100 МБ.

    Откуда берутся моды и сборки?

    Каталог работает на Modrinth. Сборки CurseForge ставятся через их официальный API: нужен бесплатный ключ с console.curseforge.com, его вставляют в Настройки.

    Что такое Horizon и как он запускается?

    Это независимый открытый проект Людовика Мари: Minecraft: Java Edition 26.3, написанный заново на Rust. Он не связан с Mojang и не содержит её кода и ресурсов, а нужные файлы берёт из вашей копии Minecraft. ZakhaRahkaZ лаунчер скачивает официальный лаунчер Horizon с GitHub и запускает его, а первая подготовка проходит уже в нём. Java-моды Fabric и Forge в Horizon не запускаются.

    Откуда иконки у модов из сборок?

    Лаунчер считает хеш каждого файла и спрашивает Modrinth, какой это проект. Если Modrinth мод не знает, а в Настройках есть ключ CurseForge, поиск идёт по отпечатку файла на CurseForge. Результат запоминается, поэтому повторно ничего не скачивается.

    Что такое аккаунт ZakhaRahkaZ?

    Бесплатный игровой аккаунт: ник и пароль, без почты и без лицензии Minecraft. Зарегистрируйтесь в лаунчере («Аккаунт» → «Аккаунт ZakhaRahkaZ») или на сайте. Ник занят только за вами, а серверы с аккаунтами ZakhaRahkaZ проверяют, что заходите именно вы. На лицензионные серверы Mojang с ним не пустят.

    Увидят ли другие мой плащ?

    На аккаунте ZakhaRahkaZ — да: скин и плащ хранятся на сервере аккаунтов, и их видят все игроки на серверах, подключённых к аккаунтам ZakhaRahkaZ. Как подключить свой сервер, написано на странице аккаунта. На офлайн-аккаунте скин и плащ видны только вам.

    Где лаунчер хранит файлы?

    Настройки и аккаунты лежат в %APPDATA%\ZakhaRahkaZLauncher, версии игры и сборки в %APPDATA%\ZakhaRahkaZ launcher. Открыть папки можно из Настроек.

    Есть ли версии для macOS и Linux?

    Пока только Windows.
